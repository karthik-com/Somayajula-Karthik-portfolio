## 🚀 Deployment

### GitHub Pages Setup

1. **Configure `vite.config.js`:**
   ```javascript
   export default defineConfig({
     base: '/Somayajula-Karthik-portfolio/',
     // ... rest of config
   })
   ```

2. **Add Deploy Script to `package.json`:**
   ```json
   {
     "scripts": {
       "deploy": "npm run build && git add dist -f && git commit -m 'Deploy to GitHub Pages' && git subtree push --prefix dist origin gh-pages"
     }
   }
   ```

3. **Deploy:**
   ```bash
   npm run deploy
   ```

4. **GitHub Settings:**
   - Go to Settings → Pages
   - Source: `gh-pages` branch
   - Select `/` (root)
   - Save

5. **Verify:**
   - Website should be live at: `https://karthik-com.github.io/Somayajula-Karthik-portfolio/`

### Custom Domain (Optional)
Create a `CNAME` file in `public/` folder with your domain name to use a custom domain.
